# Global Olympic Sports Performance Analysis

## Project Overview
An interactive Tableau project exploring Olympic sports performance using athlete-level Olympic records.

## Live Tableau Dashboard
[View the interactive Tableau Story](https://public.tableau.com/views/Global_Olympic_Sports_Analysis_17935389764910/Story1)

## Dashboards
- **Dashboard 1:** Olympic Games Medal Analysis
- **Dashboard 2:** Athlete Performance Analysis

## Key Analysis Areas
- Medal-winning athlete records by country
- Medal-winning records across Olympic years
- Sports and season comparisons
- Medal records by gender and age group
- Gold, Silver, and Bronze distribution

## Tools Used
- Tableau Desktop
- Tableau Public
- GitHub

## Project File
`Global_Olympic_Sports_Analysis.twbx`

## Data Note
The analysis uses athlete-level records. Counts represent athlete or medal records in the dataset, not necessarily official Olympic medal-table totals.
